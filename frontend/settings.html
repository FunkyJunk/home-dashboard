Security

Passkeys
A passkey replaces a password with your device’s own biometrics — Face ID on iPhone, Windows Hello on a PC. The private key never leaves the device; the server only ever stores a public key. Registering the first passkey switches authentication on for every API route. Until then the dashboard is open to anything that can reach it.
